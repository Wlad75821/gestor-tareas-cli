# Gestor de Tareas CLI

Aplicación de consola desarrollada en Python para administrar tareas personales.

## Funcionalidades previstas

- Agregar tareas
- Listar tareas
- Completar tareas
- Eliminar tareas

## Requisitos

- Python 3
- Git

## Ejecución

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
python app.py
```

## Estado

Estructura inicial de la fase 1. Las funciones se implementarán en ramas separadas durante la práctica.
